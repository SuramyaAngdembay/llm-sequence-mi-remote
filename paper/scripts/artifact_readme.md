# Anonymized code and artifact package

Supplementary material for *What Do Benign-Trained Session Language Models
Actually Detect? A Mechanistic Audit on Insider-Threat Benchmarks.*

This package contains the analysis code and the numerical result summaries
behind every table, figure, and claim in the paper. It is anonymized:
identifying paths, usernames, hostnames, and repository URLs are replaced by
neutral placeholders (`<DATA_ROOT>`, `<HOME>`, `<CLUSTER>`, `<PROJECT>`,
`<USER>`, `<REPOSITORY>`, `<AUTHOR>`).

## What is included

- `code/` — the reproducible pipeline (Python):
  - `build_session_jsonl*.py` — serialize CERT user-days into the
    `DAY`/`PSY`/`SES` text format; `--profile-mode` produces the profile
    ablation variants; `--repair-hyphenated-cols` the repaired serializer.
  - `train_qlora.py` — benign-only QLoRA adaptation.
  - `extract_adapter_deltas.py` — token-level adapter deltas + adapted-NLL
    scoring.
  - `sae_core.py`, `train_delta_sae_frontier.py` — top-k sparse autoencoder
    over deltas (`--benign-only` for dictionaries fit without positives).
  - `eval_token_delta_sae_causal.py`, `eval_token_delta_sae_necessity.py` —
    patching (τ) and ablation (ν) estimands with matched/dose-matched
    controls, same-user exclusion, and donor matching.
  - `feature_token_attribution.py` — line-class attribution mass m_f(c).
  - `cluster_bootstrap_token_delta_sae.py` — user-level cluster bootstrap.
  - `select_matched_controls.py`, `norm_normalized_contrast.py` —
    dose-matched controls and per-unit-norm sensitivity.
  - `within_user_day_ranking.py`, `masking_bootstrap_ci.py`,
    `make_masked_session_jsonl.py`, `make_swap_counterfactuals.py` —
    score-level counterfactual analyses.
  - `reselect_token_sae_features.py`, `audit3b_select_attribute.py` —
    held-out / LOUO feature reselection and the audit driver.
  - `cross_arch_probe.py` — classical-detector permutation-importance probe.
  - `factorial/` — train-matched serialization counterfactuals: paired
    user-level cluster bootstrap over fold-aligned rows (`fold_boot.py`),
    PSY-novelty check (`profile_novelty.py`), scale comparison
    (`scale_invest.py`).
  - `lanl/` — LANL cyber1 checks (host constancy, token lengths, AP and
    prevalence; `lanl_checks.py`).
  - `anvil_friend/` — the cluster runners for the factorial (3B and 8B) and
    the LANL conditions, with the environment notes that made them run.
  - `configs/` — model, SAE-frontier, and training YAML configs.
- `paper_gen/` — scripts that regenerate the paper's tables and figures
  from the result summaries.
- `results/` — numerical summaries (JSON/CSV/Markdown) for every reported
  experiment: attribution masses, intervention estimands with bootstrap
  intervals, seed-alignment, masking/swap contrasts, benign-dictionary
  robustness, the 3B repaired-serializer rerun, matched-control and
  norm-audit outputs, the TWOS replication, the cross-architecture
  probe, the train-matched factorial (`train_matched_factorial/`: per-fold
  rows, bootstrap, SAE verdicts, novelty check, README with every number
  used in the paper), and the LANL authentication-log replication
  (`lanl_auth_replication/`: AUC/AP per serialization, host-constancy and
  token-length measurements).

## What is not included (and how to obtain it)

- **Model weights.** The base models (Qwen3-8B, Qwen2.5-3B) are downloaded
  from their public sources; adapters are produced by `train_qlora.py`.
- **Large caches.** Token-delta caches and per-example score parquets are
  hundreds of gigabytes and are regenerated by `extract_adapter_deltas.py`.
- **Datasets.** CERT r4.2/r6.2, TWOS, and the LANL cyber1 log are obtained
  from their respective providers under their own terms;
  `build_session_jsonl*.py` consumes the raw CERT exports (the
  `--profile-mode` flag builds the factorial's four serializations).

## Reproduction order

1. `build_session_jsonl_fast.py` → serialized `train/val/eval.jsonl`.
2. `train_qlora.py` → benign-only adapter.
3. `extract_adapter_deltas.py` → deltas + `example_scores.parquet`.
4. `train_delta_sae_frontier.py` → sparse dictionary.
5. `reselect_token_sae_features.py` / gap ranking → feature sets.
6. `eval_token_delta_sae_{causal,necessity}.py` + `cluster_bootstrap_*` →
   intervention estimands with intervals.
7. `feature_token_attribution.py` → profile-vs-behavior masses.
8. Train-matched factorial: rebuild the four serializations with
   `--profile-mode`, repeat steps 2–3 per condition, score with
   `eval_fold_aligned_detector_metrics.py`, then `factorial/fold_boot.py`.
9. `paper_gen/generate_tables.py`, `paper_gen/generate_figures.py` →
   paper tables and figures.

Paths are placeholders; set them to local locations before running.
