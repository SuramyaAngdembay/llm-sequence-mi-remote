\begin{abstract}
The label problem is fixed for the main CERT data and score evaluations.
The main language-model adapters remain usable. Some internal experiments and
comparison models still need repair because labels influenced their fitting or
selection. The clearest complete finding is that scoring behavior targets
improves r4.2 ranking while the model still sees profile information. That
improvement does not yet tell us which internal mechanism caused it.
\end{abstract}
\section{The core question}
We turn one employee's day into text containing profile fields and session
activity. A language model adapted only on non-insider users assigns an anomaly
score: the average surprise of the next tokens. We want to know whether its
score reflects suspicious behavior, unusual profiles, or exposure during training.

These are three different experiments:
\begin{enumerate}
\item Change which token losses enter the score, leaving the input and model fixed.
\item Change profile input or adaptation, and measure the resulting predictions.
\item Edit an internal feature and measure the resulting change in output.
\end{enumerate}
Success in the first does not establish the mechanism in the third.

\section{What we can currently conclude}
% claims: C05 C06 C07 C08 C09 C28 C31 C32 C33 C34
\paragraph{Evaluation population matters.}
The main LM's fold day ROC is \rv{r42.all_users.day_roc} on r4.2 and
\rv{r62.all_users.day_roc} on r6.2 when many comparison users were seen in training.
Restricting comparison users to those absent from adaptation gives
\rv{r42.unseen_users.day_roc} and \rv{r62.unseen_users.day_roc}. This identifies a
large evaluation gap; it does not isolate its sole cause. Nine newly included
r4.2 insiders have especially poorly ranked incident-window days.

\paragraph{Changing the score helps on the complete r4.2 population.}
The separate score-decomposition pass covers all 70 insiders:
\begin{center}\input{../tables/recovery_behavior.tex}\end{center}
Behavior-only scoring means averaging losses on behavior targets, while the
model still reads the full profile. Its day-ROC gain is \rv{c32.gain}, with a
95\% descriptive user-bootstrap interval \rv{c32.gain.ci}. This is useful score
mitigation; internal profile independence is unproven. Average precision is not
the fraction of alerts that would be correct at a selected threshold. The tables
report equal-insider fold means, not pooled metrics.

\paragraph{Other comparisons are narrower.}
In separate r6.2 factorial adapters, removing profiles from both training and
scoring improves ranking in the audited 3B and 8B runs. There is one seed per
condition and only five insiders, so this is not a general model-size law.
Removing profile training targets while retaining the input does not establish
an additional improvement over behavior scoring. Cached numeric temporal models
also have corrected results, but history-copying and causal explanations remain
open. The full reading edition gives the separate populations and numerical caveats.

\section{How interpretability fits in}
% claims: C11 C12 C13 C14 C17 C19 C35 C38 C43
We compare the internal states of the frozen model with adapters on and off:
$\delta=h_{\rm adapted}-h_{\rm base}$. A sparse autoencoder approximates these
changes using a few learned directions. We select candidate directions, edit
them, and compare the output change with active and random controls. We also
measure where features activate in the input.

This is a way to investigate the score, not an automatic explanation. A feature
at a session token can use earlier profile context. The size of an intended edit
can differ from the edit actually represented in low precision. We therefore
check the realized perturbation and compute unedited and edited losses in the
same numerical configuration. Sparse coding and optimization ideas remain useful
methodological ingredients, but we are not asserting a new mathematical theorem.

\section{What is still unresolved}
% claims: C10 C15 C16 C18 C20 C21 C22 C23 C24 C25 C26 C27 C29 C30 C36 C37 C39 C40 C41 C42 C44 C45 C46
The corrected internal pilot completed 4,740 scored conditions on 316 receivers,
but one control token missed its fixed norm-matching tolerance. Its original
global gate remains failed. Separate diagnostics show sensitivity to selected
edits but do not establish attack specificity. A small control-policy probe is
not a replacement for a fully validated experiment.

Historical profile-swap and H6 responses can be retained for the fixed inputs.
Their corrected class summaries and partner checks do not restore the original
matching. Old attribution, transfer, robustness, and mechanistic replication
claims remain pending wherever fitting or selection used the wrong labels.

The comparison models need separate repair: saved local-autoencoder training
membership is contaminated in 94/120 r4.2 and 8/8 r6.2 bundles, and the old
sequence baselines share the faulty fold construction. Their old scores do not
establish that QLoRA is better. TWOS and LANL have separate unresolved issues and
are not cleared replications. Small personality-novelty associations remain
exploratory.

\section{Where this leaves the paper}
The defensible current story is that population choice and score construction
matter, and that score mitigation does not settle internal information use.
The interpretability method stays in the paper. The next experiments should
repair the specific dependencies needed to answer the internal question, with
frozen endpoints and controls. All three editions now use the same corrected
result registry; the complete reading edition carries the technical details.
This is a recovery working edition, not a claim that every causal result is repaired.
